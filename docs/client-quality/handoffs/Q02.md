  the measurement, not the optimization.
- Scaling runs have 3 measured ticks; they are discovery, not sustained capacity. The 30-minute
  mixed/churn soak is Q19. The 3000-tick churn run is not a soak.

  coverage is overlapping geometric area, not exact alpha/pixel coverage. C++ allocation counts
  exist only in the allocation-tracking build. The icon benchmark does not measure GPU residency.
- Replayed packets and TCP peers are mock evidence, not live-server evidence.
